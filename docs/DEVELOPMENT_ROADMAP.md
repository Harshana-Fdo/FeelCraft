# Development roadmap

1. **Public foundation.** Set up independent apps, scripts, documentation, health endpoint and proxy. Build the landing page, category and template routes, five original vector templates and a recipient demo. Verify lint, build, API smoke tests and mobile navigation.
2. **Database and authentication.** Implemented migrations, starter seeds, registration, login, token rotation, protected drafts and catalog endpoints. Verified on XAMPP MariaDB 10.4.32. MySQL 8 integration, email verification and password recovery remain pending.
3. **Dashboard and design editor.** Implemented draft management, Zustand and React-Konva editing, photos, document validation, preview and autosave. Separate media management and favorites remain planned.
4. **Publishing and recipients.** Implemented immutable snapshots, sharing, passwords, expiration, revocation, opens, reporting and animated recipient pages. Review this phase before beginning Phase 5.
5. **Administration.** Add category and template management, moderation and the remaining 30 templates.
6. **Advanced features and deployment.** Add music, QR codes, image export, broader accessibility and performance tests, and prepare production hosting.

Payment processing remains a separate future integration.
