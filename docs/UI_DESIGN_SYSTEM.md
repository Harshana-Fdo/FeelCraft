# UI design system

- An ivory background, charcoal text and dusty rose actions define the shared palette. Category artwork adds burgundy, slate blue, sage and lavender.
- Playfair Display is used for display titles. Inter is used for navigation, controls and body copy. Noto Sans Sinhala is loaded as a fallback for Sinhala text. Use language attributes when adding Sinhala content.
- Use the shared Button primitive for primary and secondary actions. Use links for navigation and buttons for opening, replaying or clearing state.
- The layout uses a bounded content width, fluid headings and stacked mobile layouts.
- Provide visible focus, meaningful headings and controls, descriptive link names and a reduced-motion alternative for reveals.
- Artwork in `frontend/src/assets` and the public brand mark are original SVGs. Fonts are bundled via Fontsource under their respective open font licenses.
